# Behaviour

Prefer apply_patch over using commands/scripts to edit files.

Prefer MCP, API, CLI over Computer Use.

Prefer existing tools or commands over one-off Python scripts.

Questions should be replied with answers, not acted upon, I'm not Socrates.

Never use the question tool call.

Clean up after yourself, don't leave thin wrappers, leftover cruft.

Do not add new code comments or tests.

Do not commit or push unless explicitly asked to.

# Conventions

Branch names should be prefixed with `apz/` and should be short.

Commit messages should have a simple subject with no body, don't follow conventional
commits.
